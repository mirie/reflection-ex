# Reflection Examples

Small examples exploring the reflection pattern with different agent setups:

- LangChain
- Google ADK
- A plain iterative loop

## Setup

Install the project and its dependencies:

```bash
uv sync
```

## Run an example

```bash
uv run reflection-langchain
uv run reflection-iterative-loop
uv run adk run src/reflection_ex/examples/google_adk_reflection
```

These are starter examples; the reflection logic is still being built.
